# Dry Run adopters

This file intentionally starts empty. The project does not invent users, installations, logos, or production claims.

If your team uses Dry Run and wants to be listed, open a pull request with:

- organization or project name and a public URL;
- the workflow you use (evaluation, deterministic replay, tracing, human review, or self-hosting);
- a contact who is authorized to approve the listing;
- whether the name/logo may be used in project documentation.

Private use is equally welcome and never requires disclosure. Anonymous installation telemetry is not collected.
